# 🌍 Country Explorer

A simple API-based web project built using HTML, CSS and JavaScript.

## Features

- Search any country
- Live API data
- Country flag
- Capital
- Population
- Region
- Sub-region
- Currency
- Languages
- Country code
- Responsive design
- Error handling
- GitHub Pages ready

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
- REST API

## Free API

REST Countries:
https://restcountries.com/

## Run Locally

Open `index.html` in a browser.

No backend or database is required.

## GitHub Pages

Upload these files to a GitHub repository and enable GitHub Pages:

Settings → Pages → Deploy from branch → main → /root
